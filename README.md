# OKYS_OnlineKutuphaneYonetimSistemi
Bu proje, İstanbul 29 Mayıs Üniversitesi YBS-OOP dersi 2. hafta uygulaması kapsamında geliştirilmiştir.

## Proje Hakkinda
OKYS, üyelerin kütüphaneden kitap aramasını, ödünç almasını ve kütüphane görevlilerinin bu işlemleri sistem üzerinden takip etmesini sağlayan temel bir Nesne Yönelimli Programlama (OOP) uygulamasıdır. Proje kapsamında Java ile kalıtım (inheritance) ve kompozisyon (composition) ilişkileri kurularak nesneler modellenmiştir.

## Depo (Repository) icerik
* **"src/"** : Projenin Java kaynak kodlarını (Kitap, KitapKopyasi, Kullanici, OduncKaydi) içerir.
* **"doc/"** : Projenin gereksinim analizi (SRS) belgesini ve Draw.io ile çizilmiş UML (Use Case ve Class) diyagramlarını içerir.

## Kullanilan Teknolojiler
* Java
* UML (Draw.io)
